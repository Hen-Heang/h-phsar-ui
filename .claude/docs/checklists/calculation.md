# Calculation — 수량·총량 산정 정합성 체크리스트

> 누적 수량·총량 계산의 정확성과 최종 단계 재검증에 관한 원칙.
> 언어·도메인에 무관한 범용 원칙만 다룬다. 구체적 구현 예시는 lang 파일 참조.

## CALC-01 — 누적 수량 계산 정합성

**원칙:**
상한·잔여량 등 누적 수량을 산정할 때는 모든 항목(기준값, 누적 사용량, 예정량)을 빠짐없이 반영해야 한다. 누적 값(상한 − 사용량 − 예정량)이 음수가 되지 않도록 차단하고, 경계값(잔여량 0, 정확히 상한과 같은 값)과 동시 요청 시나리오까지 테스트로 검증해야 한다.

**검증 질문:**
- 총량 기준 잔여량 공식에 사용하는 항목(기준값, 누적량, 예정량 등)이 전부 반영되어 있는가?
- 누적 값이 음수가 발생했을 때 명시적으로 차단하는가?
- 경계값(잔여량 0, 상한과 정확히 같은 값)에 대한 테스트가 있는가?
- 동시 요청 시 경쟁 조건이 발생해도 누적 값이 음수로 가지 않도록 보장되는가?

**심각도:** Critical

## CALC-02 — 최종·배치 단계 불변식 재검증

**원칙:**
앞 단계(화면·승인·사전 검증 등)에서 이미 검증했더라도, 최종 실행 단계(배치·실제 처리 직전)에서 상한·잔여량 등 불변식을 다시 검증해야 한다. 사전 검증 이후 상태가 바뀔 수 있으므로, 실제 처리 진입 시점에 재확인하지 않으면 상한 초과·이중 처리가 발생할 수 있다.

**검증 질문:**
- 실제 처리(배치 진입·최종 커밋 직전)에서 상한·잔여량을 다시 조회하고 검증하는가?
- 사전 검증과 최종 처리 사이에 상태가 바뀌어도 안전하게 처리되는가?
- 불변식 위반 시 해당 건을 건너뛰거나 중단하는 명시적 처리가 있는가?

**심각도:** Critical
